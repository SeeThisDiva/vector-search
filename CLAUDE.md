- **Mission**: HNSW Approximate Nearest Neighbor Search from scratch in Rust (`#![forbid(unsafe_code)]`, `std` only) vs FAISS.
- **Current State**: **Milestones M0–M5 (Phases 1–7) are complete** (`223` default Rust tests [`35` lib unit + `188` across `18` integration files in `tests/`] + `56` Python `pytest` tests, `0` skipped; `11` `--features instrument` tests pass).
  - **Phase 5 (`M3`)**: Evaluated `100k` and `1M` authentic SIFT1M filtered search across `S1`, `S2`, and `S3` (`Option C`, `reps=5`, `48` cells + `70`-arm sensitivity + `18` opaque `eval_limit=16_384` probes per scale) in [`results/phase5/FINDINGS.md`](./results/phase5/FINDINGS.md).
  - **Phase 6 (`M4`)**: Implemented isolated [`src/quantized/`](./src/quantized/mod.rs) (`CompactHnswGraph`, `HnswSq8Index`, `HnswPqIndex`) keeping `src/hnsw.rs` `f32` paths untouched (`0x80af03bd7aebaade` / `0x44044886c62bca5e`). Selected **Way A `sq8_query_shifted`** (`4.6115e-5` vs `63.9910` adversarial cancellation error) and benchmarked `11` `100k` arms (`reps=3`) + `9` Tier 1+2 `1M` arms (`reps=5`, sharded `0x0004`/`0x0400`) in [`results/phase6/PROPOSAL.md`](./results/phase6/PROPOSAL.md) & [`results/phase6/FINDINGS.md`](./results/phase6/FINDINGS.md): streaming `sq8_only_qbuild` cuts `1M` build RSS to `277.29 MiB` (`-56.9%` vs `f32_m16`), `SQ8+Rerank (R=20)` restores `100%` of `f32` recall, and `PQ16+Rerank` (`1M`) delivers `+27.0%` QPS / `-40.2%` `p99` at `>= 0.99` recall.
  - **Phase 7 (`M5`)**: Benchmarked Rust `HnswIndex` head-to-head against `faiss-cpu 1.15.1` `IndexHNSWFlat` (`SIMDLevel_NONE` baseline SSE2 parity) across `C1`/`C2`/`C3`/`C2-nkp` at `100k` & `1M` (`22` run JSONs + [`results/phase7/matched_recall_summary.json`](./results/phase7/matched_recall_summary.json)) in [`results/phase7/FINDINGS.md`](./results/phase7/FINDINGS.md): Rust wins `C1` at `R* >= 0.98` (`1.2546x` QPS / `1.3793x` lower `p99` at `1M R*=0.98`), `C2-nkp` (`keep_pruned_shrink=false`) isolates the default `C2`/`C3` deficit (`1.0371x` QPS / `1.5661x` lower `p99` at `1M R*=0.995`), Rust saves `~524–526 MiB` isolated Peak RSS at `1M`, trails FAISS OpenMP build by `8.96x`/`8.19x`, and reaches `83.5%–93.9%` of FAISS `1M` multi-thread batch QPS (`T in {6, 16}`).
